# Changelog — Dashboard Capsule AI

All notable changes to the Dashboard Capsule AI platform will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

---

## [2.0.0] - 2026-08-03

### Added
- **Multi-Agent AI Platform**: Autonomous agent workforce (Data Analyst, DAX Specialist, UX Designer, Security Auditor) evaluating dashboards.
- **Real-Time Collaboration**: WebSocket presence tracking and CRDT canvas synchronization in `@dcaps/viewer`.
- **Generative AI Dashboard Builder**: Prompt-to-dashboard AST compilation engine.
- **Digital Twin Simulation Engine**: Monte Carlo scenario forecasting on client WASM data models.
- **Autonomous Intelligence & Telemetry**: Self-healing performance monitoring and security alert rules.

---

## [1.0.0] - 2026-08-03

### Added
- Initial production release of Dashboard Capsule AI.
- PBIX & Multi-BI Ingestion Engine (Power BI, Tableau, Looker, Qlik).
- AI Pre-Packaging Validation & Optimization Engine (DAX KEEPFILTERS refactoring).
- `.dcaps` Secure Capsule Format (Gzip, AES-256-GCM, ECDSA P-384 signatures).
- Client-side WebAssembly Viewer Runtime.
- AI Copilot with RAG vector search over metadata.
- Secure Sharing Platform with passcode protection and dynamic SVG watermarks.
- Real-Time Analytics Platform with ClickHouse columnar event storage.
- AI Dashboard Health Engine (0–100 Weighted Score).
- Enterprise Administration Portal (SOC2/GDPR reports, feature flags, backups).
- Third-Party Plugin SDK (`@dcaps/sdk`) and Marketplace.
