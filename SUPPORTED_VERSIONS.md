# Supported Versions & Maintenance Lifecycle

Dashboard Capsule AI follows Semantic Versioning (SemVer 2.0.0). Below is the support lifecycle matrix for current and upcoming platform releases.

| Version Branch | Release Date | End of Active Support | End of Security Patches | Status |
| :--- | :---: | :---: | :---: | :---: |
| **v1.0.0** | August 2026 | August 2028 | August 2029 | **Current LTS Release** |
| **v1.1.0 (Planned)** | Q4 2026 | Q4 2028 | Q4 2029 | Feature Planning |
| **v2.0.0 (Roadmap)** | Q2 2027 | Q2 2029 | Q2 2030 | Architectural Roadmap |

## Patch Release Policy

* **Patch Releases (v1.0.x)**: Contain security fixes, bug resolutions, and performance optimizations. Zero breaking changes guaranteed.
* **Minor Releases (v1.x.0)**: Introduce new feature extensions, multi-BI adapters, or UI component additions. Backward compatible.
* **Major Releases (v2.0.0)**: Reserved for breaking protocol or schema updates with full automated migration tools provided.
